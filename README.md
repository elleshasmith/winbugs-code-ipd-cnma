# WinBUGS Code for Component Network Meta-Analysis Methods for Combining Individual Participant Data and Aggregate Data

This repository contains the WinBUGS code used in:

Component Network Meta-Analysis Methods for Combining Individual Participant Data and Aggregate Data, Research Synthesis Methods

## Contents
- MainEffectsCNMAIPDCovSLAModel.txt: WinBUGS model code for Model D: CNMA of IPD and aggregate data with study-level covariate-adjustment
- MainEffectsCNMAIPDCovModel.txt: WinBUGS model code for Model E: CNMA of IPD and aggregate data with individual-level and study-level covariate-adjustment

## Notes
- The data are not included due to data sharing restrictions (individual participant data from multiple studies).
